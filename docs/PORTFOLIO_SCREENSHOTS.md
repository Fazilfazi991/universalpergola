# Portfolio screenshot plan

Capture the demo at 1440 × 1000 with the full sidebar visible and no browser chrome.

Recommended sequence:

1. `director-dashboard.webp` — `/dashboard`
2. `crm-leads.webp` — `/dashboard/enquiries`
3. `clients.webp` — `/dashboard/customers`
4. `project-operations.webp` — `/dashboard/projects`
5. `finance.webp` — `/dashboard/payments` or `/dashboard/accounts` when that production module is included in the demo branch
6. `reports.webp` — `/dashboard/reports`

Use only synthetic records. Avoid screenshots containing upload controls, private-file previews, real contact information, or mutation dialogs.
