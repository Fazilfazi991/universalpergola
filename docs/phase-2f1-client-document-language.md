The quotation reference is the source for the system defaults below. The application keeps each quotation's `terms` field editable, so a quotation-specific override continues to replace the default without changing an issued revision.

| Client reference wording | System default wording | Meaning retained |
| --- | --- | --- |
| Advance Payment: 50% | Advance Payment: 50%. | Yes |
| Second Payment: 40% | Second Payment: 40%. | Yes |
| Final Payment: 10% | Final Payment: 10%. | Yes |
| Any changes in the dimensions, finish, & models will have a different pricing. | Changes to dimensions, finish, or models will result in different pricing. | Yes |
| The company have the right to take photo by professional photographer after installation. | The company reserves the right to take photographs after installation. | Yes |
| 3D design only for reference. | 3D designs are provided for reference only. | Yes |
| Advance paid will not be refunded. | Advance payments are non-refundable. | Yes |
| If the work is not awarded the design charges should be paid by the customer. | If the work is not awarded, design charges are payable by the customer. | Yes |
