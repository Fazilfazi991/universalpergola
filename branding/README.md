# Universal Pergola branding source

This directory keeps the client-supplied official logo source separate from the
public application bundle.

## Official source

- `universal-pergola-logo-official.pdf` is the Canva-supplied master artwork.

## Application asset

The optimized transparent PNG used by the web UI and PDF generator is:

- `public/brand/universal-pergola-logo.png`

It was derived from the official PDF above, preserves the original aspect ratio,
and removes the page background so the logo can sit on dark, light, and paper
surfaces without a white rectangle. No replacement or redrawn artwork is used.
